# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/yourusername/interviewAI.git
```

Move into the project

```bash
cd interviewAI
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Open

```
http://localhost:3000
```
